# Frontend Setup & Usage Guide

## 🎨 What's Included

A minimal, clean web interface for testing your RAG system with:
- Real-time server status monitoring
- Document upload with drag & drop
- Document management (view, delete)
- Query interface with adjustable parameters
- Answer display with source citations
- Responsive design (works on mobile too!)

**Tech Stack:** Pure HTML, CSS, and vanilla JavaScript (no frameworks, no build step)

---

## 🚀 Quick Start

### Terminal 1: Start Backend (if not running)
```bash
npm run dev
```

### Terminal 2: Start Frontend
```bash
npm run frontend
```

Then open: **http://localhost:8080**

That's it! You're ready to test the RAG system.

---

## 📖 How to Use

### 1. Check Connection Status
Look at the top of the page:
- ✅ **Green dot** = Backend is running and ready
- ❌ **Red dot** = Backend is offline (start it with `npm run dev`)

### 2. Upload Documents

**Supported Formats:**
- PDF (`.pdf`)
- Microsoft Word (`.docx`, `.doc`)
- Excel (`.xlsx`)
- Plain Text (`.txt`)
- Max size: 20 MB

**Steps:**
1. Click "Choose a file..." or drag & drop
2. Select your document
3. Click "Upload & Process"
4. Wait for processing (you'll see a success message with chunk count)

### 3. View Documents
All uploaded documents appear in the "Uploaded Documents" section:
- **Status badges:**
  - 🟢 **READY** - Document is processed and searchable
  - 🟡 **PROCESSING** - Still being processed
  - 🔴 **FAILED** - Processing failed (check backend logs)
- **Delete button:** Remove documents you don't need

### 4. Ask Questions

**Steps:**
1. Type your question in the text area
2. (Optional) Adjust parameters:
   - **Results slider (1-10):** How many document chunks to retrieve
   - **Min Score slider (0-1):** Minimum similarity threshold
3. Click "Ask Question"
4. Wait for the answer (usually 5-10 seconds)

**Tips:**
- Be specific in your questions
- If no relevant answer, try lowering the Min Score
- Questions work best when related to uploaded documents

### 5. View Answers
The answer section shows:
- **Main answer:** Generated by the LLM based on your documents
- **Sources:** Specific document chunks used to generate the answer
  - Each source shows the filename, chunk number, and relevance score
  - Higher score = more relevant to your question
- **Metadata:** Shows if the query was rewritten for better results

### Change Backend URL

If your backend runs on a different port, edit `frontend/app.js` line 2:

```javascript
const API_BASE_URL = 'http://localhost:3000';  // Change to your backend URL
```

### Change Frontend Port

```bash

```

## 🐛 Troubleshooting

### "Server not responding" (Red Status)

**Cause:** Backend is not running or unreachable

**Fix:**
```bash
# Terminal 1: Start backend
cd rag-langgraph
npm run dev

# Wait for "Server started" message
# Then refresh frontend page
```

### Upload Fails

**Possible causes:**
1. **File too large** - Max 20MB per file
2. **Unsupported format** - Only PDF, DOCX, DOC, XLSX, TXT
3. **Backend error** - Check backend terminal for errors

**Fix:**
- Try a smaller file
- Verify file format is supported
- Check backend logs

### No Answer or Empty Answer

**Possible causes:**
1. **No documents uploaded**
2. **Question not relevant to documents**
3. **Min Score too high**

**Fix:**
- Upload relevant documents first
- Make questions more specific
- Lower Min Score slider (try 0.5)
- Check backend logs for LLM errors

### CORS Errors in Browser Console

**Cause:** Backend CORS not configured for frontend URL

**Fix:** Backend already configured for `localhost:8080`. If using different port:

1. Edit `src/api/server.ts` line ~28:
```typescript
app.use(cors({
  origin: ['http://localhost:8080', 'http://localhost:YOUR_PORT'],
  // ... rest of config
}));
```

2. Restart backend

### Layout

The frontend is responsive and works on:

### Adding Features

The code is organized for easy modifications:
- **`index.html`** - Structure and layout
- **`styles.css`** - All styling and theming
- **`app.js`** - All functionality and API calls

Key functions in `app.js`:
- `checkServerStatus()` - Health check
- `handleUpload()` - File upload
- `handleQuery()` - Question asking
- `refreshDocuments()` - Get document list
